# NiYA-Data-Analysis-Portfolio

Practical project work completed as part of the NiYA Data Analysis course. This repository showcases end-to-end data processing, exploratory data analysis using Python and SQL, data cleaning, and analytical dashboards.

## 🛠️ Tools & Technologies Used
* **Python & Jupyter Notebook:** Data manipulation and visualization (Pandas, Matplotlib).
* **SQL (pgAdmin/PostgreSQL):** Data extraction, filtering, and summary queries.
* **Microsoft Excel:** Data cleaning, pivot tables, and analytical dashboards.

## 📊 Project Highlights
* Processed and cleaned raw datasets containing over 11,000 rows.
* Built automated SQL queries to extract key business insights.
* Designed visual dashboards and charts to track metrics and performance.
